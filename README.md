# Storage Check

เครื่องมือ Python สำหรับตรวจพื้นที่ดิสก์บน macOS มีหลายโหมด โหมดที่ใช้อ่านอย่างเดียวปลอดภัย ส่วนโหมดที่ลบจะแสดงผลก่อนเสมอ และต้องใส่ `--yes` จึงจะทำจริง

## ความต้องการ

- macOS
- Python 3 (ใช้เฉพาะ standard library ไม่ต้องติดตั้งอะไรเพิ่ม)

## วิธีใช้

```bash
cd "/Users/chanyut/Documents/storage check"
python3 scan.py <โหมด> [--yes]
```

การสแกนทั้ง home folder อาจใช้เวลาหลายนาที

## GUI (หน้าเว็บบนเครื่องตัวเอง)

```bash
cd "/Users/chanyut/Documents/storage check"
python3 gui.py
```

เบราว์เซอร์จะเปิดที่ `http://127.0.0.1:8765` อัตโนมัติ ถ้าไม่เปิด ให้พิมพ์ URL นี้เอง

**ต้องเปิดผ่าน `gui.py` เท่านั้น** อย่าเปิด `static/index.html` ด้วย Live Server หรือดับเบิลคลิกไฟล์ เพราะหน้าเว็บเรียก API ที่ `gui.py` ตอบอยู่ ถ้าเปิดแบบนั้นจะขึ้น error ว่าได้รับคำตอบที่ไม่ใช่ JSON

หน้าจอแบ่งเป็น 5 การ์ดหลัก และตัวเลือกเพิ่มเติม ผลการตรวจล่าสุดจะถูกบันทึกไว้ เปิดหน้าใหม่แล้วจะเห็นผลเดิมพร้อมเวลาที่สแกน กด "ตรวจอีกครั้ง" เพื่อสแกนใหม่

- **แคชของแอป** ดูและเลือกรายการ cache ที่ลบได้ แล้วย้ายไปถังขยะ
- **ไฟล์ขนาดใหญ่** ดูไฟล์ที่ควรตรวจก่อนลบ กรองตามประเภท (วิดีโอ ไฟล์บีบอัด ข้อมูล ฯลฯ) หรือกรองเฉพาะไฟล์ที่ไม่ได้เปิดมาเกินเกณฑ์ แล้วย้ายที่เลือกไปถังขยะ ไฟล์ ⛔ เลือกไม่ได้
- **ไฟล์ซ้ำ** ไฟล์ที่เนื้อหาเหมือนกันทุกไบต์ ระบบเก็บฉบับที่แก้ไขล่าสุดไว้ให้เสมอ
- **โฟลเดอร์ซ้ำ** โฟลเดอร์ที่ไฟล์ข้างในเหมือนกันทั้งหมด ระบบเก็บโฟลเดอร์ที่แก้ไขล่าสุดไว้ให้เสมอ
- **เครื่องมือนักพัฒนา** ดู dry-run ของ Docker, Homebrew, conda และ pnpm แล้วค่อยเคลียร์ตามที่แสดง (ไม่แตะ Docker volumes)

ตัวเลือกเพิ่มเติมมี
- **โฟลเดอร์ที่ใช้พื้นที่มากที่สุด** กดเพื่อเข้าไปดูโฟลเดอร์ย่อยทีละชั้น กลับได้ด้วย "ย้อนกลับ" หรือ "ขึ้นหนึ่งระดับ" และกด "ยกเว้น" เพื่อไม่ให้โฟลเดอร์นั้นถูกตรวจ
- **บันทึกและเปรียบเทียบ** บันทึกรายงาน แล้วเลือก snapshot เพื่อดูว่าโฟลเดอร์ใดโตขึ้นหรือเล็กลง และมีไฟล์ใหญ่ใหม่อะไรบ้าง
- **ตั้งค่า** เกณฑ์ขนาดไฟล์ใหญ่ เกณฑ์ไฟล์ซ้ำ เกณฑ์ว่าเก่ากี่เดือน และรายการโฟลเดอร์ที่ยกเว้น การเปลี่ยนค่าจะมีผลกับการตรวจครั้งถัดไป

ในรายการทุกแถวมีปุ่ม **เปิดใน Finder** ใช้เปิดตำแหน่งของไฟล์หรือโฟลเดอร์นั้นเพื่อตรวจรายละเอียดก่อนตัดสินใจ ปุ่มนี้ใช้ได้เฉพาะรายการใน home และไม่ลบอะไร

วันที่ "ไม่ได้เปิดนาน" ใช้เวลาที่ระบบบันทึกว่าไฟล์ถูกอ่านครั้งล่าสุด ซึ่งเป็นค่าโดยประมาณ อาจไม่ตรงกับการใช้งานจริงเสมอไป

GUI ใช้ฟังก์ชันจาก `scan.py` โดยตรง ไม่ต้องติดตั้งอะไรเพิ่ม เซิร์ฟเวอร์รับคำขอจาก `127.0.0.1` เท่านั้น กด Ctrl+C ใน Terminal เพื่อปิด ถ้าขึ้น "Address already in use" แปลว่ามี gui.py ค้างอยู่ ให้รัน `pkill -f gui.py` แล้วเปิดใหม่

### โครงสร้างหน้าเว็บ

```
gui.py          เซิร์ฟเวอร์และ API
static/
  index.html    โครงหน้า
  css/          base.css (ธีมและส่วนหลัก), sheet.css (หน้าต่างรายการ)
  js/           แยกตามหน้าที่ เช่น api.js, sheet.js, trash.js, scan.js
```

แก้ไฟล์ใน `static/` แล้วโหลดหน้าใหม่ได้เลย ไม่ต้องรีสตาร์ต `gui.py` แต่ถ้าแก้ `gui.py` ต้องปิดแล้วเปิดใหม่

## โหมด (ใช้ใน Terminal)

| โหมด | ทำอะไร | ลบอะไรไหม |
|---|---|---|
| `scan` | แสดงไฟล์และโฟลเดอร์ใหญ่สุด | ไม่ |
| `report` | บันทึก `reports/report_*.md` และ `.csv` พร้อม snapshot ไว้เทียบ | ไม่ |
| `diff` | เทียบกับ snapshot ล่าสุด แสดงส่วนที่โตขึ้นและไฟล์ใหม่ | ไม่ |
| `tools` | ดูและเคลียร์ cache ของ Docker, Homebrew, conda, pnpm ด้วยคำสั่งของเครื่องมือนั้น | ใส่ `--yes` เท่านั้น |
| `clean-cache` | ย้าย cache ใน `~/Library/Caches` และ `~/.cache` ที่ใหญ่กว่า 100 MB ไปถังขยะ | ใส่ `--yes` เท่านั้น |
| `interactive` | เลือกไฟล์ทีละหมายเลข แล้วยืนยันก่อนย้ายไปถังขยะ | ถามก่อนเสมอ |
| `duplicates` | หาไฟล์ที่เนื้อหาเหมือนกันทุกไบต์ตั้งแต่ 10 MB ขึ้นไป แสดงกลุ่มและพื้นที่ที่คืนได้ | ใส่ `--yes` เท่านั้น เก็บฉบับที่แก้ไขล่าสุดไว้ ที่เหลือไปถังขยะ |

ตัวอย่าง

```bash
python3 scan.py report                 # บันทึกจุดเปรียบเทียบ
python3 scan.py diff                   # ดูว่าอะไรโตขึ้นตั้งแต่ครั้งก่อน
python3 scan.py tools                  # ดูว่าจะเคลียร์อะไรได้บ้าง (dry-run)
python3 scan.py tools --yes            # เคลียร์จริง
python3 scan.py clean-cache            # ดูรายการ cache (dry-run)
python3 scan.py clean-cache --yes      # ย้าย cache ไปถังขยะ
python3 scan.py interactive            # เลือกไฟล์ที่จะลบเอง
python3 scan.py duplicates             # ดูไฟล์ซ้ำ (dry-run)
python3 scan.py duplicates --yes       # ย้ายไฟล์ซ้ำที่ไม่ใช่ฉบับล่าสุดไปถังขยะ
```

## ป้ายประเภท

- `🟢 cache` โฟลเดอร์ cache หรือ log ที่สร้างใหม่ได้
- `🟡 ตรวจก่อน` ไฟล์ทั่วไปที่ควรตรวจก่อนลบ
- `⛔ ห้ามลบ` ข้อมูลที่ไม่ควรแตะ เช่น Docker, iCloud, Photos, Keychains โหมด `interactive` จะไม่แสดงรายการนี้

## ความปลอดภัย

- โหมดที่ลบจะย้ายไปถังขยะผ่าน Finder ไม่ได้ลบถาวร กู้คืนได้จากถังขยะ
- `tools` ไม่แตะ Docker volumes และใช้เฉพาะ prune ของ image ที่ไม่มีแท็กและ build cache
- ป้าย `🟡` ไม่ได้หมายความว่าลบได้ ควรตรวจวันที่ใช้งานและเนื้อหาก่อนเสมอ
- `clean-cache --yes` จะย้าย cache ทั้งหมดที่ใหญ่กว่า 100 MB ซึ่งเป็นของที่สร้างใหม่ได้ แต่แอปที่กำลังเปิดอยู่อาจต้องใช้เวลาสร้างใหม่

## ข้อควรระวัง

- ถ้าอ่าน `~/Library` หรือ `~/.Trash` ไม่ได้ ให้เพิ่มสิทธิ์ **Full Disk Access** ให้ Terminal ที่ System Settings → Privacy & Security
- ครั้งแรกที่ใช้การย้ายไปถังขยะ macOS อาจถามให้ Terminal มีสิทธิ์ควบคุม Finder ให้กด Allow

## การตั้งค่า

ค่าที่ปรับได้ในหน้าเว็บ (ส่วน "ตั้งค่า") จะถูกเก็บใน `settings.json` ในโฟลเดอร์เครื่องมือ

| ค่า | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `min_mb` | ขนาดขั้นต่ำของไฟล์ที่แสดงและเก็บใน snapshot | 100 MB |
| `dup_min_mb` | ขนาดขั้นต่ำของไฟล์และโฟลเดอร์ที่หาว่าซ้ำ | 10 MB |
| `old_months` | ถือว่าไม่ได้เปิดนานเมื่อเกินกี่เดือน | 12 |
| `exclude` | โฟลเดอร์ที่ไม่ให้ตรวจ (รูปแบบ `~/...`) | ว่าง |

ค่าอื่นแก้ในต้นไฟล์ `scan.py` ได้

| ตัวแปร | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `TOP_N` | จำนวนรายการที่แสดงในแต่ละส่วน | 30 |
| `SKIP_DIRS` | โฟลเดอร์ที่ข้ามตอนสแกน | `.git`, `node_modules`, `.venv`, `venv` |
| `NEVER` | เส้นทางที่ติดป้าย "ห้ามลบ" | Docker, iCloud, Photos, Keychains |
| `CACHE` | เส้นทางที่ติดป้าย "cache" | `/Caches/`, `/.cache/`, `/Logs/` |

## ไฟล์ที่เครื่องมือสร้าง

- `snapshots/` จุดเปรียบเทียบที่ใช้โดย `diff` (สร้างโดย `report`)
- `reports/` รายงาน `.md` และ `.csv`
- `cache/last_scan.json` ผลสแกนล่าสุดที่หน้าเว็บใช้แสดงตอนเปิด
- `settings.json` ค่าตั้งค่าและรายการโฟลเดอร์ที่ยกเว้น

ทั้งสองโฟลเดอร์อยู่ในโฟลเดอร์เครื่องมือ และจะถูกข้ามตอนสแกน จึงไม่ปนเข้าไปในผลลัพธ์
