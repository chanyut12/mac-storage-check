# Storage Check

เครื่องมือตรวจพื้นที่ดิสก์บน macOS ทั้งแบบ CLI และหน้าเว็บบนเครื่องของคุณเอง

- ใช้เฉพาะ Python standard library ไม่ต้องติดตั้งอะไรเพิ่ม
- โหมดที่อ่านอย่างเดียวปลอดภัย โหมดที่ลบจะแสดงผลก่อนเสมอและต้องยืนยัน
- ทุกการลบย้ายไปถังขยะ กู้คืนได้

## เริ่มต้นใช้งาน

```bash
cd "/Users/chanyut/Documents/storage check"
python3 gui.py
```

เบราว์เซอร์จะเปิด `http://127.0.0.1:8765` อัตโนมัติ ถ้าไม่เปิดให้พิมพ์ URL นี้เอง

> **ต้องเปิดผ่าน `gui.py` เท่านั้น** อย่าเปิด `static/index.html` ด้วย Live Server หรือดับเบิลคลิกไฟล์ หน้าเว็บเรียก API ที่ `gui.py` ตอบอยู่ ถ้าเปิดแบบอื่นจะขึ้นข้อความว่าได้รับคำตอบที่ไม่ใช่ JSON

เซิร์ฟเวอร์รับคำขอจาก `127.0.0.1` เท่านั้น กด `Ctrl+C` ใน Terminal เพื่อปิด ถ้าขึ้น `Address already in use` แปลว่ามี `gui.py` ค้างอยู่ ให้รัน `pkill -f gui.py` แล้วเปิดใหม่

การสแกนทั้ง home folder อาจใช้เวลาหลายนาที ผลล่าสุดจะถูกเก็บไว้ เปิดหน้าใหม่จะเห็นผลเดิมพร้อมเวลาที่สแกน กด **ตรวจอีกครั้ง** เพื่อสแกนใหม่

## หน้าเว็บ

### การ์ดหลัก

| การ์ด | ทำอะไร |
|---|---|
| **แคชของแอป** | ดูและเลือก cache ที่ลบได้ แล้วย้ายไปถังขยะ |
| **ไฟล์ขนาดใหญ่** | ดูไฟล์ที่ควรตรวจก่อนลบ กรองตามประเภทหรือตามวันที่ไม่ได้เปิด แล้วย้ายที่เลือกไปถังขยะ |
| **ไฟล์ซ้ำ** | ไฟล์ที่เนื้อหาเหมือนกันทุกไบต์ ระบบเก็บฉบับที่แก้ไขล่าสุดไว้ให้เสมอ |
| **โฟลเดอร์ซ้ำ** | โฟลเดอร์ที่ไฟล์ข้างในเหมือนกันทั้งหมด ระบบเก็บโฟลเดอร์ที่แก้ไขล่าสุดไว้ให้เสมอ |
| **เครื่องมือนักพัฒนา** | ดูคำสั่งที่จะรันก่อนเคลียร์ของ Docker, Homebrew, conda, pnpm, npm และ pip ไม่แตะ Docker volumes และมีปุ่มอัปเดตแพ็กเกจ Homebrew ที่ล้าสมัย |

ไฟล์ที่มีป้าย ⛔ เลือกไม่ได้ และรายการที่เลือกจะถูกย้ายไปถังขยะหลังมีกล่องยืนยันเสมอ

### ตัวเลือกเพิ่มเติม

- **โฟลเดอร์ที่ใช้พื้นที่มากที่สุด** กดแถวเพื่อเข้าไปดูโฟลเดอร์ย่อยทีละชั้น กด **⬆ ขึ้นหนึ่งระดับ** เพื่อกลับไปยังโฟลเดอร์แม่ และกด **ยกเว้น** เพื่อไม่ให้โฟลเดอร์นั้นถูกตรวจ
- **บันทึกและเปรียบเทียบ** บันทึกรายงาน แล้วเลือก snapshot เพื่อดูโฟลเดอร์ที่โตขึ้นหรือเล็กลง และไฟล์ใหญ่ใหม่
- **สรุปรายสัปดาห์** เทียบกับ snapshot ที่เก่ากว่า 7 วันขึ้นไป (ใช้ snapshot ใหม่ที่สุดในกลุ่มนั้น) ถ้ายังไม่มี snapshot ที่เก่าพอ ให้กด **บันทึกรายงาน** ไว้ก่อน
- **ตั้งค่า** เกณฑ์ขนาดไฟล์ใหญ่ เกณฑ์ไฟล์ซ้ำ จำนวนเดือนที่ถือว่าไม่ได้เปิดนาน และรายการโฟลเดอร์ที่ยกเว้น การเปลี่ยนค่ามีผลกับการตรวจครั้งถัดไป

### ปุ่มที่ใช้บ่อย

- **เปิดใน Finder** ทุกแถวมีปุ่มนี้ ใช้เปิดตำแหน่งของไฟล์หรือโฟลเดอร์เพื่อตรวจรายละเอียดก่อนตัดสินใจ ใช้ได้เฉพาะรายการใน home และไม่ลบอะไร
- **เลือกทั้งหมด** เลือกเฉพาะรายการที่ย้ายได้ (ฉบับ **เก็บไว้** เลือกไม่ได้)
- **กรองตามประเภท** เช่น วิดีโอ ไฟล์บีบอัด ข้อมูล เอกสาร โมเดล AI
- **ส่งออก CSV** ดาวน์โหลดรายการที่แสดงอยู่ตอนนี้ (หลังค้นหาและกรองแล้ว) เป็นไฟล์ CSV สร้างในเบราว์เซอร์ ไม่ส่งข้อมูลออกนอกเครื่อง

> วันที่ "ไม่ได้เปิดนาน" ใช้เวลาที่ระบบบันทึกว่าไฟล์ถูกอ่านครั้งล่าสุด ซึ่งเป็นค่าโดยประมาณ

## CLI

```bash
python3 scan.py <โหมด> [--yes]
```

| โหมด | ทำอะไร | ลบไหม |
|---|---|---|
| `scan` | แสดงไฟล์และโฟลเดอร์ใหญ่สุด | ไม่ |
| `report` | บันทึก `reports/report_*.md` และ `.csv` พร้อม snapshot สำหรับเทียบ | ไม่ |
| `diff` | เทียบกับ snapshot ล่าสุด แสดงส่วนที่โตขึ้นและไฟล์ใหม่ | ไม่ |
| `tools` | ดูหรือเคลียร์ cache ของ Docker, Homebrew, conda, pnpm, npm, pip | ใส่ `--yes` เท่านั้น |
| `brew-upgrade` | แสดงแพ็กเกจ Homebrew ที่ล้าสมัย และอัปเดตด้วย `brew upgrade` | ใส่ `--yes` เท่านั้น |
| `clean-cache` | ย้าย cache ใน `~/Library/Caches` และ `~/.cache` ที่ใหญ่กว่าเกณฑ์ไปถังขยะ | ใส่ `--yes` เท่านั้น |
| `interactive` | เลือกไฟล์ทีละหมายเลข แล้วยืนยันก่อนย้าย | ถามก่อนเสมอ |
| `duplicates` | หาไฟล์ซ้ำตั้งแต่ 10 MB แสดงกลุ่มและพื้นที่ที่คืนได้ | ใส่ `--yes` เท่านั้น เก็บฉบับที่แก้ไขล่าสุดไว้ |

ตัวอย่าง

```bash
python3 scan.py report              # บันทึกจุดเปรียบเทียบ
python3 scan.py diff                # ดูว่าอะไรโตขึ้นตั้งแต่ครั้งก่อน
python3 scan.py tools               # ดูว่าจะเคลียร์อะไรได้ (dry-run)
python3 scan.py tools --yes         # เคลียร์จริง
python3 scan.py duplicates          # ดูไฟล์ซ้ำ (dry-run)
python3 scan.py duplicates --yes    # ย้ายไฟล์ซ้ำที่ไม่ใช่ฉบับล่าสุดไปถังขยะ
```

## ป้ายประเภท

| ป้าย | ความหมาย |
|---|---|
| 🟢 cache | โฟลเดอร์ cache หรือ log ที่สร้างใหม่ได้ |
| 🟡 ตรวจก่อน | ไฟล์ทั่วไปที่ควรตรวจวันที่ใช้งานและเนื้อหาก่อนลบ |
| ⛔ ห้ามลบ | ข้อมูลที่ไม่ควรแตะ เช่น Docker, iCloud, Photos, Keychains |

ป้าย 🟡 ไม่ได้แปลว่าลบได้ ควรตรวจก่อนเสมอ

## ความปลอดภัย

- การลบทุกครั้งย้ายไปถังขยะผ่าน Finder กู้คืนได้จากถังขยะ
- รายการที่ติดป้าย ⛔ และพาธนอก home จะถูกปฏิเสธที่ระดับฟังก์ชันย้ายไฟล์ ไม่ว่าจะเรียกจากหน้าเว็บหรือ CLI
- `tools` ไม่แตะ Docker volumes และใช้เฉพาะ prune ของ image ที่ไม่มีแท็กกับ build cache
- `clean-cache --yes` จะย้าย cache ที่สร้างใหม่ได้ แต่แอปที่เปิดอยู่อาจต้องใช้เวลาสร้างใหม่
- เซิร์ฟเวอร์ไม่รับคำขอจากเครื่องอื่น

## การตั้งค่า

ค่าเหล่านี้ปรับได้ในหน้าเว็บ (ส่วน **ตั้งค่า**) และเก็บใน `settings.json`

| ค่า | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `min_mb` | ขนาดขั้นต่ำของไฟล์ที่แสดง | 100 MB |
| `dup_min_mb` | ขนาดขั้นต่ำของไฟล์และโฟลเดอร์ที่หาว่าซ้ำ | 10 MB |
| `old_months` | ถือว่าไม่ได้เปิดนานเมื่อเกินกี่เดือน | 12 |
| `exclude` | โฟลเดอร์ที่ไม่ให้ตรวจ รูปแบบ `~/...` | ว่าง |

ค่าอื่นแก้ในไฟล์ `storagecheck/config.py` ได้ เช่น `TOP_N`, `SKIP_DIRS`, `NEVER` และ `CACHE`

## โครงสร้างโค้ด

```
scan.py                 จุดเข้าของ CLI
gui.py                  เซิร์ฟเวอร์และ API ของหน้าเว็บ
storagecheck/
  config.py             ค่าตั้งค่า พาธ และค่าคงที่
  safety.py             ป้ายประเภท รายการห้ามลบ และการย้ายไปถังขยะ
  walk.py               เดินไฟล์ในโฮม ดัชนีไฟล์ และการสแกนไฟล์ใหญ่
  hashing.py            hash ของไฟล์ พร้อมแคชและการ hash แบบขนาน
  duplicates.py         ไฟล์ซ้ำและโฟลเดอร์ซ้ำ
  history.py            ผลสแกนล่าสุด snapshot รายงาน และการเทียบ
  tools.py              เครื่องมือนักพัฒนา
  cleanup.py            เคลียร์ cache และโหมดเลือกเอง
  cli.py                แยกคำสั่งไปยังโหมดต่าง ๆ
static/                 หน้าเว็บ (HTML, CSS, ES modules)
```

การเพิ่มโหมดใหม่ใน CLI ให้เขียนฟังก์ชันในโมดูลที่เกี่ยวข้อง แล้วเพิ่มการเรียกใน `storagecheck/cli.py`

## ไฟล์ที่เครื่องมือสร้าง

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `snapshots/` | จุดเปรียบเทียบที่ใช้โดย `diff` และหน้าเปรียบเทียบ |
| `reports/` | รายงาน `.md` และ `.csv` |
| `cache/last_scan.json` | ผลสแกนล่าสุดที่หน้าเว็บโหลดตอนเปิด |
| `cache/hash_cache.json` | hash ที่คำนวณแล้ว ใช้ข้ามไฟล์ที่ไม่เปลี่ยน |
| `settings.json` | ค่าตั้งค่าและรายการโฟลเดอร์ที่ยกเว้น |

ไฟล์เหล่านี้มีชื่อและข้อมูลการใช้งานของคุณ จึงไม่ควรนำขึ้น version control

## ข้อควรระวัง

- ถ้าอ่าน `~/Library` หรือ `~/.Trash` ไม่ได้ ให้เพิ่มสิทธิ์ **Full Disk Access** ให้ Terminal ที่ System Settings → Privacy & Security
- ครั้งแรกที่ย้ายไปถังขยะ macOS อาจถามว่าอนุญาตให้ Terminal ควบคุม Finder หรือไม่ ให้กด Allow
- atime ของไฟล์จะเปลี่ยนเมื่อถูก hash ดังนั้นการหาไฟล์ซ้ำอาจทำให้ค่า "ไม่ได้เปิดนาน" ของไฟล์เหล่านั้นไม่ตรงความจริงในรอบถัดไป
